Daily Hacker News for 2026-09-18

The 10 highest-rated articles on Hacker News on September 18, 2026 which have not appeared on any previous Hacker News Daily are listed below, with Chinese summaries for quick reading.

  1. Wax motor
    comments

    石蜡电机（Wax motor）是一种利用石蜡相变体积膨胀（5%–20%）将热能转化为机械能的线性执行器，主要由密闭石蜡、活塞杆、热源及偏置复位机构组成。相比电磁阀，它具有输出推力大（可达约4000 N）、动作平缓无冲击、可利用环境热源实现无源控制等优势。该器件被广泛应用于航空航天流体控制、HVAC恒温混合阀、滚筒洗衣机门锁、温室自动通风调节及微机电系统（MEMS）微执行器等领域。

  2. Astra for Law
    comments

    OpenAI 推出面向律所与法律科技公司的 Astra for Law，将 GPT-6 Astra 模型与包含超 2.3 亿条数据的法律搜索索引相结合，在 Vals AI 基准测试中取得 54% 的准确率，显著提升法律检索能力。该平台提供零数据保留（ZDR）与隐私控制等专业级合规保障，并联合 Sullivan & Cromwell 等顶尖律所开发合同分析和交易尽调等专属工作流。此外，OpenAI 还发布了 26 款连接 iManage、Thomson Reuters 等专业工具的生态插件及 ChatGPT for Word，全面对接律所现有业务系统。

  3. Bend – A language that blocks AI mistakes via proof, on CPU and GPU
    comments

    Bend 是一种结合 Python 语法、C 语言性能、CUDA 并行能力与 Lean 形式化证明的编程语言，旨在通过数学证明防止 AI 在编程中产生错误。开发者可在 LAWS.bend 中定义规则，由 Bend 在极短时间内完成证明检查，从数学层面保证 AI 提交的代码绝不破坏预设法则。此外，Bend 具备原生代码编译与自动并行化机制，无需手动编写线程或锁即可在多核 CPU 及 GPU 上实现高效运行。

  4. Bonsai 2 27B: Near-Lossless Compression in a 9x Smaller Footprint
    comments

    PrismML 推出基于 Qwen3.8 27B 的开源模型 Ternary Bonsai 2 27B，采用 {-1, 0, +1} 三元权重与 FP16 分组缩放，有效位数仅 1.76 bits/weight，模型总体积缩小至 5.9GB 并支持 262K 上下文及多模态输入。相比全精度模型，其体积缩小超 9 倍，却保留了 98.2% 的综合基准性能，显著提升了推理、编程、视觉及 Agent 任务的表现。在运行性能上，该模型在 RTX 5090 上吞吐量达 143 tokens/s，在 RTX 4090 上能效比全精度 8B 模型高出 40%，且全面支持 CUDA 和 Apple MLX 框架。

  5. A heap overflow and SSO misconfiguration to compromise OpenAI internal repos
    comments

    Hacktron安全团队利用Discourse论坛中libheif图像解码器的堆缓冲区溢出漏洞与OpenAI SSO配置缺陷组合成漏洞链，实现了对OpenAI员工ChatGPT及Codex账户的无交互接管。研究人员利用受害者账户在OpenAI内部代码库中成功提交PR以证明危害，潜在可威胁GitHub、Slack和邮件等关联集成服务。利用Claude Opus 5等AI模型协助，团队仅耗时数小时即完成了RCE漏洞利用脚本的开发与适配。目前漏洞已通报相关方完成修复，OpenAI向研究团队支付了6500美元赏金。

  6. OpenJev
    comments

    SemIf 是一个利用 WebGPU 在浏览器中纯本地运行开源模型进行语义决策的实验项目。它对比了两种决策提取路径：一种是无需解码直接读取选项 logits 并进行归一化，另一种则是逐 Token 自回归生成包含选项概率的 JSON 文本。项目支持 Qwen3 0.6B、MiniCPM5 2B 及 Qwen3.5 4B 等不同规格的 GGUF 量化模型，模型权重与输入数据均完全保留在浏览器缓存中，方便用户在其本地 GPU 上实测两种方法的运行性能与精度差异。

  7. Microsoft exec called AI scraping 'the largest theft of labor in human history'
    comments

    在《纽约时报》等媒体起诉OpenAI和微软的版权诉讼最新解封文件中，披露了微软高管曾私下将两家的AI数据抓取行为斥为“人类史上最大规模的劳动力盗窃”。文件详细记录了OpenAI与微软利用绕过付费墙、批量抓取新闻及故意删除版权声明等手段构建训练集，涉及数十万份新闻作品。此外，微软内部数据证实其Copilot导致《纽约时报》点击率暴跌高达93%，且双方高管均承认AI产品对出版商构成替代性与“生存威胁”，这严重削弱了OpenAI的“合理使用”抗辩理由。

  8. I don't like passkeys
    comments

    作者 Ethan Hawksley 认为，Passkey 虽能有效防御钓鱼攻击与服务器数据泄露，但对个人用户而言尚不成熟，反而增加了永久锁户与设备丢失等风险。平台同步 Passkey 存在账号一旦被封禁即失去所有凭证的锁定风险，而硬件密钥又面临成本高昂、存储容量有限且难以备份导出等问题。此外，第三方密码管理器集成与跨设备登录体验依然割裂，且整体安全性仍受制于脆弱的恢复机制，因此现阶段使用独立 TOTP 配合随机密码对个人而言更加安全可控。

  9. Cloudflare Quick Tunnels
    comments

    Cloudflare 推出 Quick Tunnels 服务，只需一条指令即可将本地服务转换为 Cloudflare 边缘网络上的公网加密 URL，无需注册账号、配置 DNS 或开放入站端口。该连接采用单向出站机制，自动继承 HTTPS 加密与 DDoS 防护，且隧道随进程终止而自动销毁。特别针对 AI 代码 Agent 时代进行了优化，支持 stdout 的 JSON 结构化输出，便于 Agent 循环测试、Webhook 回调及团队协作。

  10. Android 17 is the first since 3.x to add new APIs without releasing to the AOSP
    comments

    Android 17 QPR1 是自 3.x 以来首个未同步发布至 AOSP 即新增开发者 API 的版本，目前新 API 及部分安全补丁仅由 Google Pixel 独占，其他 OEM 需等到 2026 年 12 月的 QPR2。GrapheneOS 指责 Google 延迟提供 GPL 源码和安全补丁的做法构成不公平竞争，大幅增加了第三方系统的维护成本。目前 GrapheneOS 已完成 QPR1 的移植，但因授权限制需靠逆向工程提取补丁，并计划未来进一步加强与 Motorola 的合作以及对 Pixel 11 等设备的支持。
