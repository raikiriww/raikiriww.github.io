  1. Socratic Tutor
    comments

  2. Hyper-realistic sand with WebGL2
    comments

    该项目是一款基于 WebGL2 与 JavaScript 构建的超逼真网页流沙模拟器，支持在手机、平板及桌面端浏览器中直接运行。用户可通过触控或鼠标推抹沙粒，倾斜设备利用重力引导流沙滑移，或通过晃动手机将沙粒打散。应用内置了五种不同特性的沙子类型与底衬材质切换，并结合动态光照、颗粒拟真音效与触觉反馈，提供沉浸式的沙盘物理交互体验。

  3. A false smoke alarm almost drowned Jane Street's only NYC datacenter
    comments

    Jane Street 前系统团队工程师回忆了一起险些摧毁纽约核心机房的事故：施工扬尘误触烟雾报警器后，联锁机制关闭了机房空调，同时干式消防喷淋管道完成注水充压。失去制冷导致机房温度急剧上升，一旦突破约 150°F 的热敏阈值，自动喷淋将喷水彻底淹没机房。住在附近的作者紧急赶回现场，在温度飙升至 143.6°F 的危急关头徒手拔除所有机柜电源阻止了灾难，随后用 OCaml 编写了直接采集全量服务器温度并计算均值告警的监控程序。

  4. Gemini Decisions API
    comments

    Google DeepMind 推出由全新 Gemini Decision 1 模型驱动的 Gemini Decisions API，专为工具选择、策略检查、模型路由及上下文评分等闭集决策任务打造。该 API 支持在单次前向传递中直接处理涵盖文本、图像、音频、视频和 PDF 的多模态输入，可同时评估多达 1,000 个是否题、多选题或量表评分问题，无需逐字生成文本即可直接返回概率与置信度评分。其端到端延迟仅为 150 至 250 毫秒，定价为每百万输入 tokens 0.10 美元且完全不收取输出 token 费用，目前已在 Google 内部的模型路由与安全检测等场景中落地应用。

  5. United Airlines bans AI agents from booking flights on behalf of travelers
    comments

  7. 93% of paint splatters are valid Perl programs (2019)
    comments

    该文探讨了编程语言领域一个戏谑性的长期开放问题：在墙上涂抹油漆是否可能不构成合法的 Perl 代码。作者采用实证方法，利用光学字符识别（OCR）软件对100张油漆飞溅图像进行测试，发现高达93%的油漆飞溅图案均能被成功解析为有效的 Perl 程序。论文详细分析了这些油漆飞溅程序的属性并展示了无法通过解析的样本，该研究发表于2019年的恶搞学术会议 SIGBOVIK。
