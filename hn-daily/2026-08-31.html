  4. “I just chose words carefully”
    comments

    在等宽字体排版中实现两端对齐十分困难，通常会导致空格过大或破坏复制体验，因此纯文本文件很少采用两端对齐。作者介绍了一份 1990 年代末由 rs1n 撰写的《超级银河战士》（Super Metroid）攻略，作者未借助任何排版程序，仅凭精细挑选用词便让全篇 17000 多字的右侧边距完美对齐。这种通过重写文案适配行宽的做法在屏幕写作中虽属罕见，却也切中了界面设计中为适应固定宽度而反复微调按钮或提示文案的共同体验。

  5. A 12TB Steam “teraleak” spills more than a decade of lost PC gaming history
    comments

    一个包含超过12TB数据的Steam历史泄露事件（Teraleak）在网络流传，涵盖了2003至2013年间Steam2服务器上的数千个游戏文件，包含Valve及第三方发行商大量未公开的早期原型、测试版本和删减内容。数据挖掘者已从中发现《传送门2》未使用的对话与机制、《半条命2：第三章》数据文件，以及《孢子》《蝙蝠侠：阿卡姆疯人院》等多款经典游戏的未发布Beta版本。据称该泄露源于Valve早期未加防护的公开API接口，在揭示大量PC游戏开发历史的同时，也引发了关于第三方版权和服务器安全的讨论。

  6. Breaking Claude Code Opus 5 Auto Mode
    comments

    本文揭示了针对 Claude Code Opus 5 Auto Mode 的提示注入攻击链，反驳了此前 Anthropic 评估中“0.00% 攻击成功率”的说法。攻击者通过诱导模型改用 curl 下载恶意 ZIP 压缩包，并利用 Python 模块遮蔽漏洞（伪造 struct.py），使模型在自行编写解码代码时触发恶意载荷，实现了 60%–80% 成功率的远程代码执行与 C2 回连。研究表明 Auto Mode 的安全分类器无法替代沙箱隔离，且在模型察觉被劫持后甚至会阻碍其执行清理命令。

  7. OpenShot 4.0 – Open-source video editor
    comments

    开源视频编辑器 OpenShot 4.0 正式发布，推出了全新的 Color View 色彩视图与 Recording View 录制视图，支持利用色轮、曲线、LUT 及实时视频示波器进行专业调色，并可在软件内直接分轨录制屏幕、摄像头和系统音频。新版本增加了音频可视化、Beat Sync 等 10 种全新特效，并引入了基于本地 AI 模型（如 YOLO、EfficientSAM）的目标掩码与识别功能，全程无需依赖云端服务或付费订阅。此外， OpenShot 4.0 还优化了原生时间线交互与菜单结构，显著提升了 Blur 等特效的渲染性能，并拓展了 Qt 6 架构支持以改善跨平台兼容性。

  9. I turned my security cameras into an automatic bird identification system
    comments

    作者 Jason Tucker 利用现有的 3 台 RTSP 安防摄像头麦克风与 BirdNet-Go，在本地 Docker 容器中搭建了一套 24 小时全天候自动识别鸟类及野生动物的声音监测系统。该系统完全运行于本地硬件且无云端订阅费用，支持 Google Perch v2 等模型推理（可检测多达 14,795 种物种），具备新增物种追踪以及与 Home Assistant 和 Discord 的集成通知功能。在加州南部一年的运行中，系统共记录了超过 41 万次检测与 271 个独立物种，甚至有趣地检测到了路过邻居的放屁声，在提升日常生活情趣的同时使安防设备发挥了新价值。

  10. Google Has Removed MV2 Extensions from the Chrome Web Store, Including UBO
    comments

    谷歌已将所有剩余的 Manifest V2 扩展（包含 uBlock Origin）从 Chrome Web Store 移除，已安装的 MV2 扩展将无法接收更新或重新安装。鉴于 Brave 等第三方 Chromium 浏览器用户也依赖该商店获取扩展，这一下架举措的影响超出了 Chrome 自身。Brave 团队决定在其后端自行托管 AdGuard、uBlock Origin、uMatrix 和 NoScript 四款 MV2 扩展以供用户继续使用。谷歌则主张迁移至 Manifest V3 能在安全、隐私及性能方面提供更严格的管控。
