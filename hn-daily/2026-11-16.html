  1. Claude Code and Codex reverse engineered my 1994 Jeep's ECU over a $3 Arduino [video]
    comments

    作者针对缺乏 OBD2 接口及适用诊断仪的 1994 年款 Jeep Cherokee，将一块价值 3 美元的 Arduino 开发板连接至发动机车载电脑（ECU）。在 Claude Code 与 Codex 编程 Agent 的协助下，作者在约一周内完成了逆向工程，实现了实时读取数据、转储完整程序，甚至在 ECU 内运行自定义代码并控制燃油泵等部件。相关电路接线、代码及 Agent 交互指令已开源发布，可供 1991 至 1995 年款的 Jeep 及克莱斯勒车主参考使用。

  2. Protomaps: Self-hosting map tiles has gotten cheap and easy
    comments

    作者介绍了基于 Protomaps 生态的 PMTiles 瓦片格式，该格式将地图数据打包为单文件并通过 HTTP Range 请求读取，能以极低门槛和极高便携性实现地图服务的自托管，从而避免 Mapbox 等商业 API 昂贵的用量收费。文章详细演示了通过 rclone 将每日构建的全球地图导入 Bunny.net 存储与 CDN，并配置 Range 请求缓存、防盗链与速率限制以防止账单失控的具体流程。最终只需在前端使用 MapLibre GL 配合 pmtiles 插件即可完成地图渲染，不仅具备高可用性，成本更可降至传统商业方案的百分之一左右。

  3. Handwriting, as a Font
    comments

    Ductus 是一款能将个人手写字迹转换为字体的工具。用户可以使用手指、触控笔或鼠标在设备上逐一书写 26 个字母，并支持字体的微调与导出。该工具注重隐私保护，所有字迹数据完全在本地手机或电脑设备上处理与校验，不会上传至云端服务器。

  5. Universal XSS in uBlock Origin from website-driven element picker
    comments

    安全研究员在 Firefox 版本的 uBlock Origin 元素选择器（element picker）中发现了一处一键通用跨站脚本（UXSS）漏洞，攻击者可借此诱导扩展添加任意受信任过滤器并在目标网站执行恶意 JavaScript。恶意网站首先通过 Hook 扩展脚本的 XHR 调用窃取随机生成的扩展内部 UUID，接着在隐藏 iframe 中嵌入选择器 UI 并通过 postMessage 利用换行符绕过限制注入特权脚本过滤器。最后，攻击者通过点击劫持诱骗用户点击不可见的“创建”按钮即可使规则生效，该漏洞目前已通过引入通信认证密钥等机制完成修复。

  6. Qwen4-Max
    comments

    Qwen 团队推出基于全新架构的大模型 Qwen4-Max，拥有 2.4 万亿主干参数（单 token 激活 710 亿参数）、原生视觉能力与 100 万 token 上下文窗口，并通过稀疏注意力及门控残差等技术升级实现了出色的计算效率与预训练稳定性。相较于前代 Qwen3.8-Max，该模型在长程任务和代码执行中大幅降低了 token 消耗，在 Work360 评测中使平均单任务成本下降约 62%。依托 Work360 产业评估框架，Qwen4-Max 不仅能协同专业软件完成 3D 建模、游戏引擎端到端开发与工业零件数控编程，更在金融投研、法律尽调及重症医疗等高壁垒场景中展现出强大的工具调用与全链条证据溯源能力。

  8. Many of Amazon’s Black Friday and Cyber Monday “deals” offered no savings
    comments

    Groundwork Collaborative 发布的调查报告指出，亚马逊在黑色星期五与网络星期一促销中宣传的“精选特惠”存在严重误导，近三分之一的促销商品价格在节前一个月持平或更低，并未带来实际省钱效果。研究追踪 350 多款推荐商品发现，近十分之一的“促销”商品价格反而比节前更高，部分鞋靴等产品涨幅甚至达 59% 至 83%，此类劣质交易的促销中位数价格比节前高出 19%。该机构批评此类虚假促销让消费者承受价格欺诈，并呼吁监管机构介入严打，强制要求零售商在促销时明示过去 30 天的历史最低价。
