Daily Hacker News for 2026-10-31

The 10 highest-rated articles on Hacker News on October 31, 2026 which have not appeared on any previous Hacker News Daily are listed below, with Chinese summaries for quick reading.

  1. Azure's Weakest Link – Five Full Cross-Tenant Compromises
    comments

    安全研究员披露了 Azure Logic Apps 中 API Connections 的架构缺陷，利用其在共享 API Management 实例中置换凭据的机制，发现了 5 个严重的跨租户全盘接管漏洞并斩获 20 万美元赏金。攻击者利用 ARM REST API 中的路径遍历缺陷（如 DynamicInvoke 及未公开的 DynamicList 端点），或在 Consumption 模式下篡改 host.api.RuntimeUrl 参数，可绕过不完备的输入验证并冒用受害者连接的凭证。该漏洞可导致任意租户的 Key Vault、Azure SQL 及 Jira 等外部后端服务遭到完全跨租户攻破，经报告后所有相关漏洞均已被微软修复。

  2. The $6.3B Binance hack was pulled off in just 20 minutes
    comments

    10月29日，加密货币交易所币安（Binance）遭遇史上最大规模的黑客攻击，攻击者在约20分钟内从至少10条区块链的热钱包中窃取了约63亿美元数字资产。TRM Labs与Chainalysis等多家追踪机构指出，攻击手法及混币痕迹高度指向朝鲜黑客组织TraderTraitor，起因疑似为工程师笔记本电脑失窃沦陷。目前各机构已协助冻结约28亿美元被盗稳定币，但剩余约33亿美元的比特币和以太坊等资产无法直接冻结，黑客正通过高度自动化的新型路径加速洗钱。

  3. Northflank Breached
    comments

    云平台 Northflank 发生严重安全入侵事故，多名用户报告其存放在平台上的 AI API 密钥等凭证遭到未授权调用。官方推测该攻击与近期针对 AI 凭证的恶意活动一致，紧急建议所有用户假定环境变量已全被解密，立即撤销并轮换各类全局及工作负载密钥。为遏制影响，平台联合 Wiz CIRT 展开应急响应并部署补丁，同时全面开放审计日志，陆续为 Postgres、MySQL、Redis、Minio 和 RabbitMQ 等插件服务上线了密钥轮换功能。

  4. The federated code forge
    comments

    Tangled 宣布推出基于 AT Protocol 的首个联邦化代码托管平台，结合开放协议的持久性与成熟 Forge 的易用体验，支持灵活自托管各组件且高度契合 AI Agent 扩展。系统重构了整体架构，前端采用 Svelte 并在边缘部署，配合全球分布的 Rust 内存索引器 bobbin 与重写后的 knot2 节点服务。新版本将 Issue、PR 等协作数据以 Git 对象链（COB）形式直接保存在仓库本体中以实现高度可移植性，并通过双向验真防篡改，同时上线了免密组织账户并全面支持堆叠 PR（Stacked PR）流程。

  5. Florilegium: Procedural Flowers in LaTeX
    comments

    Florilegium 是一个面向 LuaLaTeX 的程序化页面装饰开源项目，完全通过 Lua 在排版时动态计算参数化曲线并直绘入 PDF，无需依赖任何外部图像即可生成代尔夫特蓝水彩风格的花卉页边距。系统利用贪心空间填充算法自适应填补正文留白，支持响应首字下沉与标题位置、按文档页数呈现四季枯荣变化，并提供几何与数学公式主题。除原生支持 LaTeX 外，它还能独立渲染为 SVG 供 Typst 等排版系统调用，或通过基于 WebAssembly 的网页端游乐场实现实时预览与配置。

  6. My favourite PowerMac is a Nintendo Wii
    comments

    开发者 Rairii 成功将经典 Mac OS（包括 7.6 与 9.2.2）移植至采用 ArtX 芯片组的任天堂 Wii 和 GameCube 游戏机，实现了非苹果官方系统自 CHRP 时代以来首次成功引导至桌面。为了完成适配，作者基于 OpenBIOS 深度修改了引导程序 Trampoline，修正了物理地址与 MMIO 内存映射，并针对 Flipper 架构修补了内核中断驱动及 m68k 底层代码中的硬件假设缺陷。此外，作者还编写了显示驱动、手柄输入驱动以及模拟 SCSI 块设备驱动，逐步解决了启动设备枚举与镜像加载等一系列兼容难题。

    comments
