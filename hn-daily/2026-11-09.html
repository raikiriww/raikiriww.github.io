  1. Declarative Dragging
    comments

    针对传统拖拽交互需要编写大量几何、反馈与动画代码的痛点，Joshua Horowitz 等人提出了荣获 UIST 2026 最佳论文奖的“声明式拖拽”（Declarative Dragging，D2）范式。该方法采用模型驱动机制，开发者无需直接编程底层视觉行为，只需声明拖拽元素所能导向的应用未来模型状态。系统引擎会自动推测性渲染这些可能的目标状态并提取元素位置，以此自动合成为平滑、具备动画反馈的拖放交互。团队开发了面向 Web SVG 的实现库 Dragology，支持特性的可组合性，并已成功应用于多视角数学探索工具及 Hazel 编程环境的代码重构交互中。

  2. Outlook.com is rejecting email from domains without DMARC
    comments

    自 2026 年 11 月 5 日起，微软旗下 Outlook.com 与 Hotmail 等消费级邮箱在未公开公告的情况下，开始拦截未配置 DMARC 记录的域名所发送的邮件。与以往仅针对日发信量超 5000 封的大规模发件人不同，该限制已波及低发信量的普通发件人，且因部分邮件间歇性退信（报错 550 5.7.1）而极易被忽略。受影响域名只需确保 SPF 或 DKIM 正常对齐，并在 DNS 中添加一条基础的 DMARC TXT 记录（v=DMARC1; p=none）即可解决拦截问题。

  4. KetchUp – Open-source SketchUp alternative built with Rust and WebGPU
    comments

    BenchUp（原 KetchUp）是一款基于 Rust 与 WebGPU/WebGL2 构建的开源 3D 建模应用，专为木工、家具制作和 DIY 设计打造，旨在作为 SketchUp 的免费替代品。它无需注册账号，既可在主流桌面浏览器中直接运行，也提供 Windows、macOS 和 Linux 原生客户端，支持推拉成形、尺寸标注、吸附对齐及群组管理等实用建模功能。用户的所有工程数据均保存在本地设备并可导出为 .ketchup 文件，同时支持导入 SketchUp 几何结构及导出 OBJ 模型，便于在动手制作前精确规划与推敲设计。

  6. Unlocking any car from X brand in most of the world
    comments

    安全研究员 Shubham Shah 与 Sam Curry 分析了某知名汽车品牌的车联网平台，在公开暴露的管理后台与前端 JavaScript 代码包中发现了硬编码 API 密钥及身份系统的管理员凭据。研究人员利用后台无鉴权接口实现了通过车牌号和 VIN 检索车主账户敏感信息，并使用路径遍历绕过 Nginx WAF 限制以直接调用 ForgeRock OpenIDM 接口重置任意用户密码。结合车企允许跳过多因素认证（MFA）的配置缺陷，攻击者可完全接管车主账户并实现对全球任意车辆的远程解锁与控制。

  7. Is Opus 5.5 nerfed? Thinking patterns changed on November 3
    comments

    Shane Melaugh 在 X 上通过分析 1,400 次 Claude Code 会话指出，Opus 5.5 的模型名称虽未变动，但其推理模式自 11 月 3 日起发生剧烈转变。实测显示模型在“high”档位下的推理量大幅缩减，容易过快介入任务并陷入混乱而无法修复 Bug，需提升至“xhigh”档位才能正常解决问题。作者据此认为此前流行的“所有场景均使用 high 档位”策略已不再适用，验证了用户关于该模型实际表现遭到削弱（nerfed）的体验。
