    comments

  4. Safari introduces Adaptive Dark Mode in 27.3
    comments

    针对近40%用户使用暗色外观但仅约10%网页主动支持的现状，苹果在 Safari 27.3 beta 中基于 WebKit 引擎推出了自适应暗黑模式（Adaptive Dark Mode），可自动将未适配的浅色网页转换为暗色呈现。该技术通过在保留色相前提下反转亮度的色彩矩阵来调整背景与文字，确保符合 WCAG 4.5:1 对比度标准，并结合直方图与 SVG 语义分析智能修复图标与黑白徽标对比度，同时保持常规图像与 Canvas 画布不受影响。在保障快速高效渲染的同时，Safari 严格禁止网页脚本探测转换状态以防范指纹追踪保护隐私，且开发者仍可通过标准 color-scheme 规范主动定义暗色样式或选择退出转换。

  5. Nvidia RTX Spark encrypted firmware slows inference speed to 35% on Linux
    comments

    测试显示在搭载 Nvidia RTX Spark 的笔记本上运行原生 Linux 时，接通电源会导致 GPU 频率被锁死在约 780 MHz，使大模型推理速度骤降至 Windows 表现的五分之一左右。该严重降速的根因在于负责动态分配 CPU 与 GPU 功耗的平台控制器固件功耗表经过加密，目前仅 Windows 驱动具备解密密钥，Linux 开源驱动缺乏相应功耗管理逻辑。虽然断电使用电池时 Linux 性能可恢复至接近正常水平，但在 Nvidia 官方完善 Linux 驱动前，依托 Windows 驱动栈的 WSL 是当前兼顾完整 GPU 性能与 Linux AI 工具链的最佳实用方案。
