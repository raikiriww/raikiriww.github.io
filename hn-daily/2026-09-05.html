  1. Adult Film Producer Unmasks Prolific 'John DOE' Torrent Pirate as Meta Executive
    comments

    成人电影制作公司 Strike 3 Holdings 在针对 Meta 索赔 4.46 亿美元的 AI 训练侵权案中提出申请，指控一名下载近 20,000 个文件的匿名 BitTorrent 用户实为 Meta 旗下 Reality Labs 部门的高管。Strike 3 认为该高管在其住宅 IP 上下载 VR 成人影片等大量资源发生在公司向 Meta 发出警告之后，怀疑其被用于 Meta 的 AI 训练或研究，请求法院将此案与 Meta 主案合并。Meta 则回应称 IP 地址无法直接确认具体的侵权人身份，且无证据证明该住宅 IP 的下载行为与 Meta 公司存在关联。

  2. Show HN: Open-Source eInk Bike Computer
    comments

    OpenTrailPaper 是专为 LilyGO T5S3 4.7 英寸电子纸开发板打造的开源骑行码表固件，支持离线地图、GPX 路线导航、FIT 数据记录及蓝牙传感器连接，预载数据后无需手机即可独立运行。配套 iOS 应用提供路线规划、离线地图生成、骑行数据同步及固件更新等功能。目前项目处于开发者阶段，硬件存在缺乏气压高度计、多频 GPS、电子罗盘及防水外壳等局限，实测续航约为 7.4 至 8 小时。

  3. Shutting down our public encrypted DNS
    comments

    Mullvad VPN 宣布将关闭自2022年运营的公共加密 DNS（DoH）服务，转为向 Quad9 基金会提供资金支持。官方表示使用其 VPN 时已有内部 DNS 处理流量，资助专注于隐私 DNS 的 Quad9 比重复建设更具资源效率。Mullvad 浏览器默认设置将自动迁移至 Quad9，手动配置 DoH 及 iOS/macOS 配置文件的用户需在2026年11月2日前自行切换。

  4. Can AI design circuit boards yet?
    comments

    EEBench 是由 atopile 团队推出的电路设计 AI 基准测试，利用声明式代码与 SPICE 仿真评估模型在电气性能、器件容差和成本等方面的权衡能力。最新测试结果显示，Claude Opus 5 以 61.6% 的得分暂居榜首，Grok 4.6 和 Claude Fable 5.1 紧随其后，xAI 等实验室已将其纳入模型工程能力评估中。尽管 AI 已能解决部分具体的电路设计任务，但在完整硬件产品的布局、制造与全面验证上仍存在不足，前沿实验室正加速推进电子工程领域的 AI 开发。

  5. Statichost.eu – European static site hosting
    comments

    Statichost.eu 是由 Eric Selin 创办的 100% 欧洲静态网站托管平台，旨在为前端开发者提供独立于美国云基础设施的托管选择。该服务支持通过 Git 推送部署及绑定自定义域名，从代码部署到 CDN 网络的全部技术栈均运行在欧洲本土企业拥有的基础设施上。平台强调完全不依赖 AWS 或 Cloudflare 等美国厂商，以保障数据与基础设施的本土化与独立性。

  6. Actively exploited sandbox RCE in all Chromium versions
