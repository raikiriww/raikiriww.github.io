Daily Hacker News for 2026-08-13

The 10 highest-rated articles on Hacker News on August 13, 2026 which have not appeared on any previous Hacker News Daily are listed below, with Chinese summaries for quick reading.

  1. uBlock Origin Is Giving Up the Fight to Keep Ads Off Facebook
    comments

    广告拦截工具 uBlock Origin 的志愿开发团队宣布，将停止针对 Facebook 频繁变动的广告规避技术更新规则，并称其为反用户网站。Facebook 通过分割广告代码、混入不可见文本及随机化标签等手段对抗拦截，使仅由少数志愿者组成的 uBO 团队面临不可持续的维护压力。目前已有的拦截规则仍旧有效，但未来若被 Facebook 绕过，官方团队将不再主动修复，而是转由社区用户通过提交 Pull Request 自行维护。

  2. Grok 4.6
    comments

    xAI发布了新一代模型Grok 4.6，该版本在Grok 4.5的基础上进行了补充训练升级，特别专注于长期运行的智能体（agents）以及更具野心的交互和视觉工作。它在多项智能体编程与知识工作基准测试中达到前沿水平，在人工分析智能指数（AA Intelligence Index）上与GPT-5.6 Sol持平，并在长任务中展现出更强的自我测试与验证能力。目前Grok 4.6已在Cursor、Grok Build及API等平台上线，基础定价为每百万输入Token 2美元、输出Token 6美元。

  3. Delta
    comments

    Zed团队推出了专为与AI智能体协同编程及代码审查设计的多人协作环境Delta，目前已开启私有测试。该应用基于实时同步数据库DeltaDB，使代码工作区与对话历史在团队及AI之间保持同步，并支持通过WebAssembly网页端或Claude Code等终端工具参与协作。Delta将对话本身作为文档呈现，允许用户在代码行、计划步骤或智能体思考块等任意位置直接编辑和添加评论，从而有效保留开发意图和决策上下文。

  4. Codex in ChatGPT desktop app for Linux is now in preview
    comments

    ChatGPT Linux 桌面客户端已开启预览，整合了 ChatGPT、Work 和 Codex 并提供原生体验，目前支持 Ubuntu、Debian 及 Fedora 的 x64 和 ARM64 架构。社区用户对此发布表示关注，有用户询问是否存在该版本与 Windows 版本的特性对比。同时，部分用户批评官网限制用户只能下载当前系统对应客户端的设计，导致无法在 Windows 主机上直接下载 Linux 安装包并传输至虚拟机使用。

  5. Deutsche Bank becomes first foreign yuan clearing bank in Europe
    comments

    中国人民银行授权德意志银行（Deutsche Bank）在法兰克福开展人民币清算业务，使其成为首家在欧洲获得此资质的外资金融机构。此前欧洲的人民币清算服务均由中资银行提供，此次合作旨在借助德意志银行的国际网络扩大人民币在国际贸易与投资中的使用。此举为开展对华业务的欧洲企业提供了直接进行人民币结算的新途径，有助于降低交易成本并减少对美元支付路径的依赖。

  6. DeepSeek Harness developer preview
    comments

    DeepSeek Harness 已面向全球开发者推出开发者预览版并开源，其采用 Cordis 内核来管理插件的挂载、卸载及依赖。该框架将 Agent 的模型、工具、沙箱和 UI 等所有能力均实现为可插拔的插件。开发者仅需修改配置即可自由选择、替换或扩展各项能力，无需修改 DeepSeek Harness 的源代码。

  7. Gloomberb
    comments

    Gloomberb 是一款开源的股票投资组合管理器与交易终端。该平台支持研究公司的行情、图表、财务、申报文件、期权及估值等数据，并可跟踪全球指数、外汇、行业资讯等市场动态。此外，用户还可在其工作区中管理投资组合与自选股，连接券商，并使用 AI 筛选器和预测市场等功能。

  8. Spaghettifying DRAM
    comments

    开源项目 skitter-creek-bath-salts 通过修改内存层次的最底层，重写物理 DRAM 地址转换以混淆平台内存，从而暴露出内核不可见的受保护 DRAM 区域（如 PSP、SMM、微码等）。该技术通过向 DRAM 控制器写入特定比特翻转来重组内存硬件坐标，直接绕过了建立在物理地址之上的所有 CPU、芯片组及固件安全屏障。该项目在 AMD Family 16h 处理器上进行了开发与测试，并利用 DRAM 控制器地址转换的 GF(2) 线性映射特性，通过线性代数成功重建了被混淆的内存数据。

  9. Gemini 3.7 Flash
    comments

    谷歌正式推出专为编程和智能体（Agent）设计的新一代模型 Gemini 3.7 Flash，在代码调试、网页开发及多步骤规划等任务上相比前代有显著提升，且百万 Token 价格减半。该模型在 FrontierCode、DeepSWE 和 GDP.pdf 等多项基准测试中均超越 3.6 版本，展现出更强的复杂逻辑推理与代码生成能力。同时，3.7 Flash 已在个人 AI 智能体 Gemini Spark 中上线，并更新了针对化学、生物、放射性、核子（CBRN）及网络攻防等领域的安全防护。

  10. Accelerating GPT-5.6 Sol Ultrafast
    comments

    OpenAI 与 Cerebras 合作在 OpenAI API 中推出了由 Cerebras 驱动的全新服务层“极速模式”（Ultrafast Mode），并率先应用于 GPT-5.6 Sol 模型。该模式在不损失质量的情况下可实现每秒高达 750 个输出 Token，其运行速度比 Fable 5 快 11 倍，比 Opus 4.8 快 5 倍。在 Humanity's Last Exam 基准测试中，GPT-5.6 Sol 极速模式以近 7 倍的计算速度完成了评估，旨在为法律、金融及网络安全等高风险、时间敏感型工作提供实时的高阶智能支持。
