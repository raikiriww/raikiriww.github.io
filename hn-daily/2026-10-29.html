Daily Hacker News for 2026-10-29

The 10 highest-rated articles on Hacker News on October 29, 2026 which have not appeared on any previous Hacker News Daily are listed below, with Chinese summaries for quick reading.

  1. The Grid, a factory-scale robot in Massachusetts that builds PCBs on demand
    comments

    CircuitHub 正式公布了位于美国马萨诸塞州的工厂级 PCB 按需制造系统“The Grid”，该系统利用悬浮移动小车配合 AI 调度各工序机台，无需停线切换即可实现多种不同设计样板与小批量的全自动化混线生产。针对传统小批量电子制造因换线成本高而依赖离岸代工的痛点，该方案在美国本土交付周期仅需 4 天，交付速度约为深圳快板厂的两倍。该平台已稳定运行五年并服务超过 2.6 万名工程师，计划今年将产能扩充 5 倍以推动西方电子硬件供应链本土化。

  2. Emacs Turns 50
    comments

    诞生于 1976 年麻省理工学院人工智能实验室（MIT AI Lab）的全屏文本编辑器 EMACS 迎来 50 周年，其前身源自 TECO 及其扩展 Control-R，后经理查德·斯托曼（Richard Stallman）与盖伊·斯蒂尔（Guy Steele）等人标准化快捷键宏定义而成型。早期该软件以“共享并回馈改进”的公社模式分发，但后续商业公司与詹姆斯·高斯林（James Gosling）对其商业化售卖的做法，促使斯托曼创立了 GNU 项目并开发出 GNU Emacs。EMACS 不仅奠定了现代文本编辑交互并在 macOS 等系统中留下了深层快捷键支持，更直接孕育了自由软件运动与后来的 GNU/Linux 操作系统生态。

  3. Kentucky man becomes the first humanist granted religious exemption from AI
    comments

    肯塔基大学研究管理员 David Durman 认为将日常思考与决策转交给 Copilot、ChatGPT 等 AI 工具有损其道德行动能力，违背了人文主义关于人类尊严与繁荣的核心信念。在美国人文主义协会（AHA）协助下，他依据联邦民权法案第七章（Title VII）申请宗教豁免并获校方批准，成为首例因人文主义信仰获准在日常工作中免用 AI 的案例。校方经评估认定该诉求不会对部门造成不当负担，准许其在完成个人职责时免于使用 AI，这一先例也折射出当前社会及宗教界对 AI 伦理风险的深切担忧。

  4. CNC Stone Carving
    comments

    加尔默罗会修士将现代多轴数控（CNC）石雕技术与金刚石刀具引入哥特式教堂的修建中，使传统工匠耗时数月的繁复构件得以在数天内甚至夜间无人值守下高效雕刻成型。整个建造基于全数字化工作流，由艺术家进行 3D 建模后转交程序员利用 CAM 软件规划刀路与 G 代码，再由操作员配合使用线锯预切石块并监控多轴 CNC 完成精细雕琢。该实践不仅大幅降低了哥特建筑高昂的建造时间与成本，让古老建筑艺术重归现实，还将年轻一代的计算机技能有效转化为了建筑工程力量。

  5. StackOverflow now gets fewer than 1000 questions a month
    comments

    该页面展示了运行在 Stack Exchange Data Explorer 上的数据查询，旨在按月统计 Stack Overflow 平台的提问量变化趋势。该 SQL 查询通过对 Posts 表中问题类型的数据按创建年月进行聚合分组，返回了共计 220 行按时间升序排列的月度提问统计记录。页面同时提供了图表可视化呈现以及 CSV 和 XML 格式的数据下载支持。

  6. Qwenputer: A functioning, deterministic RISC-V CPU inside Qwen3.5
    comments

    开发者 Divyansh Agrawal 推出了实验性模型 Qwenputer，无需额外训练便将一个 32 位 RISC-V CPU 核心直接编译进 Qwen 3.5 的前置权重层中。该项目巧妙利用模型内部 Gated DeltaNet 线性 RNN 层的状态矩阵作为确定性 RAM 与文件存储，使 CPU 完全在模型的前向传播中执行并能运行 C 和 MicroPython 代码。Qwen 通过借用工具调用机制与内置 CPU 交互实现精确的高位算术运算，在保持模型原有对话能力的同时，也为研究隐藏思维链推理与不可篡改的内置监控等 AI 安全课题提供了新途径。

  7. Claude Code regularly sends each background agent’s transcript to its model
    comments

    Claude Code 默认约每 30 秒向模型重新发送后台 agent 的完整上下文，仅用于生成 3 至 5 个词的状态行更新，在缺少官方关闭选项的情况下消耗了用户约 15%–20% 的 token 与请求额度。针对该冗余开销，Flamerix AI 提出了无需修改二进制文件的 Bun 预加载方案，通过拦截全局定时器精准禁用该摘要请求。该方法在保留后台任务完整功能的前提下将相关 API 开销降至零，仅停用面板状态行的实时刷新。

  8. We're releasing the weights of Mistral Large 4
    comments

    Mistral AI 正式开源其在欧洲本土基础设施上从头训练的 1 万亿参数原生多模态旗舰模型 Mistral Large 4（代号 Le Chonk）权重。该模型经强化学习重点提升了 Agentic 编程能力与推理效率，在 FrontierCode 2.0 与 Terminal-Bench 4.0 等基准上名列开源权重模型前茅，并提供三种推理模式以优化 Token 成本。此外，模型在防御性网络安全与 Agent 安全防御上表现突出，恶意网络请求拒绝率达 96.6%，为追求自主可控的主权 AI（Sovereign AI）机构提供了高可靠的技术底座。

  9. Patrick Stewart has died
    comments

    英国著名演员帕特里克·斯图尔特爵士（Sir Patrick Stewart）因阿尔茨海默病与路易体痴呆症于洛杉矶家中去世，享年86岁。他早年克服贫困童年成长为皇家莎士比亚剧团的杰出舞台剧演员，曾两度荣膺英国戏剧奥利弗奖。中年转型影视后，他因在《星际迷航：下一代》中饰演沉稳威严的企业号舰长皮卡德（Jean-Luc Picard）而风靡全球，随后在《X战警》系列电影中成功塑造了深入人心的“X教授”（Professor X）。其数十年的演艺生涯兼具古典戏剧的庄重风范与涉足喜剧配音的幽默魅力，是跨越舞台与大银幕的标志性表演艺术家。
