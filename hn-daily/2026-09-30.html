  1. A Staff Engineer's Guide to Inventing Work
    comments

    本文探讨了软件平台团队在缺乏专职产品经理的背景下，Staff Engineer 如何通过捕捉多元信号来主动“发明工作”（inventing work）以提升平台价值。作者将信号来源归纳为系统（崩溃、成本、Toil）、用户（持续调研、重载场景、联合原型）、组织（OKR、管理者重复关注点、迁移遗留问题）和行业（描述性写作、时滞套利）四个维度共 11 种途径。平台团队的失败往往源于被最响亮或最新的崩溃信号所主导，因此工程人员需要根据信号的前瞻性与论据成本合理筛选并决定优先事项。

  2. A Privacy Analysis of Web and Mobile Conversational AI Agents [pdf]
    comments

    该研究对 ChatGPT、Claude、Gemini、DeepSeek 等 9 款主流对话式 AI 服务的 Web 与移动端进行了系统性的隐私追踪分析。研究发现传统的第三方广告与追踪技术已被广泛嵌入 AI 平台，导致用户提示词、生成的对话标题及公开链接等敏感资产被泄露给第三方追踪服务商。这些对话数据常与持久化用户标识符绑定，使第三方能够关联用户身份并建立长期画像，且 Cookie 同意选项与付费订阅层对此类追踪的防护作用有限。该研究揭示了对话式 AI 服务带来的新型隐私攻击面，并指出了其在 GDPR 与 ePrivacy 指令下存在的合规风险。

  4. America.gov
    comments

    America.gov 是一个整合了2.9万个官方政府网站的AI驱动一站式平台，免费且无广告，专门从联邦、州和地方官方来源解答各种政府服务问题。该平台高度重视隐私保护，不收集或存储个人信息，会话记录会在离开时自动清除。用户无需下载应用即可直接在浏览器中使用，并计划于2027年拓展功能，支持跨机构表单填写、进度跟踪以及护照申请、职位匹配等综合服务。

  5. Vermont replacing power plants with home batteries
    comments

    美国佛蒙特州最大电力公司 Green Mountain Power（GMP）通过在数千户家庭部署家用电池，构建起容量达 110 兆瓦的虚拟电厂（VPP），已成为该州最大的电力来源。该系统不仅在极端天气中为居民提供可靠的停电保障，还逐步替代了高污染、高成本的传统化石燃料峰值电厂，去年为客户节省了 1100 万美元。GMP 目标在 2030 年消除全州停电，并计划于 2034 年前将虚拟电厂规模扩大一倍以上，同时积极探索整合电动汽车电池（V2G）等分布式能源。

  6. Show HN: Real-time Solar System with 526k asteroids and all tracked satellites
    comments

    Space Now（Belle Lune 2）是一个实时太阳系及太空物体三维可视化项目，基于 CelesTrak 和 SatNOGS 数据库追踪了超过 52.7 万个太阳系天体以及约 3.5 万个人造卫星与空间碎片。数据涵盖行星、彗星、小行星、通信与导航卫星星座（如 Starlink、千帆等）以及太空碰撞和反卫星试验产生的碎片。用户可通过鼠标拖拽缩放或 WASD 键盘按键在空间中自由飞行导航，实时交互并查看各类天体的具体位置与运行轨道。

  7. Livenerf: Has Opus 5.5 been nerfed yet?
    comments

    livenerf 是一个开源且长期运行的确定性基准测试项目，旨在检测前沿 AI 模型（如 Claude Opus 5.5）在发布后是否会被暗中降配或性能下降。该项目基于 Inspect 评估框架，通过锁定 Claude Code CLI 版本与固定系统提示词，并从 GPQA Diamond、MMLU-Pro 等数据集中筛选题目构建测试集。它在模型发布后连续 30 天每日运行测试，通过比较准确率与输出 Token 数量的变化来统计和检测模型能力的漂移。

  9. You said no MCP
    comments

    Pi 过去曾公开声明不支持 MCP，但随着 MCP 本身的演进以及现代 LLM 在工具延迟加载与动态配置等能力上的提升，团队决定将其整合至核心功能中。为解决传统 MCP 工具难以灵活组合的问题，Pi 引入了运行于 harness 端的 Codemode 沙盒，允许 Agent 使用 JavaScript 动态编排并组合工具调用，从而避免浪费上下文。此项更新不仅提升了与 Jev 等工具的协同效率，也体现了 Pi 团队希望积极参与并推动 MCP 生态发展的意图。

  10. Gemini 4 Argon
    comments

    谷歌宣布推出新一代前沿模型 Gemini 4 Argon，专为真实软件工程、企业知识工作（如法律与金融）及网络安全防御等复杂长流程工作流设计，其输出 token 上限大幅提升至 100 万。该模型在 DeepSWE v1.1、AutomationBench 和 CWE-bench v1 等多项评测中表现卓越，并在谷歌内部被用于量子算法优化、数据中心内存节省及 C/C++ 到 Rust 的大规模代码迁移。Argon 初始定价为每百万输入 token 2 美元、输出 token 10 美元，目前优先面向受信任的安全团队开放体验，在持续强化防滥用与防提示词注入等安全防护后将推广至广大开发者与企业用户。
