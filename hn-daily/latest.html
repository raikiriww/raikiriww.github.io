  2. Window Sweaters
    comments

    Window Sweaters 是一款基于 JankyBorders 开发的开源 macOS 菜单栏应用，能够为桌面窗口包裹上温暖且具质感的针织毛衣风格彩色边框。该项目已为 Finder、VS Code 等 37 款常见应用手工预设了专属配色与编织花样，未适配应用则支持从其图标中自动提取色彩生成人字形等柔和纹样，同时支持通过配置文件和 PNG 图案进行深度定制。用户可通过菜单栏的毛线图标自由调节针脚大小、边框宽度与编织风格，并能针对特定应用单独开关边框显示。

  5. Claude Code sends your email address to websites
    comments

  7. Britain to make salary disclosure in job ads mandatory
    comments

    英国政府计划向议会提交立法，强制要求雇主在招聘广告中公开具体薪资或薪资范围，以此打破薪酬保密机制并提升职场薪酬透明度。官方数据显示，目前英国仅约四成雇主公布薪酬区间、不足两成公布具体数额，推行该政策旨在帮助求职者更高效地做出求职决策，并缩小长期不利于女性群体的性别薪酬差距。此项新规也是英国政府应对青年未就业问题的一揽子措施之一，使英国在薪资透明度法规上与欧盟及部分美国地区保持同步。

  8. Blender's UI and Runtime: Much Faster Than GPUI
    comments

    BUI 是一个从 Blender 代码库中解耦出的独立 UI 库，以轻量 C 语言运行时为核心，完整复刻了 Blender 的原生控件绘制、交互规则与流畅操作体验。该库无需依赖 Blender 或浏览器引擎/WebView，提供了面向 Python（全面兼容 tkinter 并支持 Qt 语法）、Rust、JavaScript/React/Svelte、C/C++ 以及 Dear ImGui 的多语言绑定。底层采用局部损伤渲染机制与可选的 GPU 渲染管线，不仅在空闲时保持零 CPU 占用，且在基准测试中展现出远超 GPUI 的渲染效率与更低的内存占用。

  9. Dutch 'idealist' bank ASN blocks non-Google Android, including GrapheneOS
    comments

    针对荷兰 ASN 银行及支付机构以“硬件密钥认证无法证明系统完整性”为由封禁包括 GrapheneOS 在内的非官方系统并强推 Play Integrity，有开发者指出该技术说辞并不成立。实际上 Android 规范中的硬件 Keystore 证书包含 RootOfTrust、启动状态及应用身份等完备信息，且 GrapheneOS 提供了公开签名密钥，完全能够由硬件背书证明系统完整性。应用开发者与金融机构普遍选择 Play Integrity 导致第三方系统被屏蔽，本质上并非基于安全考量，而是因为该方案集成成本低，且在合规审计时直接以“谷歌判定”为由抗辩远比自行解析证书和维护信任白名单更加省事。

  10. Tesla to wind down Cybertruck production
    comments
