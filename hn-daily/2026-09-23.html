The 10 highest-rated articles on Hacker News on September 23, 2026 which have not appeared on any previous Hacker News Daily are listed below, with Chinese summaries for quick reading.

  1. How did AMD Ryzen get 50% faster in two years?
    comments

    文章探讨了 AMD Ryzen 7 处理器在 2022 至 2024 年间（Zen 3 至 Zen 5）Geekbench 6 性能提升约 50% 的核心原因，指出最高睿频仅增长 15%，因此频率并非主要驱动力。性能飞跃主要得益于晶体管数量增加 50% 并用于拓宽核心架构，包括派遣宽度从 6 提升至 8、整数 ALU 增至 6 个以及重排序缓冲区扩大至 448 个条目。此外，Zen 5 架构加倍了 L2 缓存容量，并将 SIMD 算术单元及加载/存储通道全面升级为 512 位，大幅强化了并行计算能力。

  2. Can gzip be a language model?
    comments

    本文探讨了在无需神经网络和训练参数的前提下，利用 gzip 等无参压缩算法实现语言模型的可能性。基于“语言模型即压缩”的理论，gzip 依赖的 DEFLATE 算法利用 32 KiB 滑动窗口匹配字节序列，将可预测的文本压缩为更小体积以评估续写概率。为克服单字节量化噪声，作者开发了基于束搜索（Beam Search）的前瞻机制，利用 zlib 成功生成具有一定模式相关性的文本。

  3. 'We hacked the FBI:' Hackers say they have data on all FBI employees
    comments

    知名黑客组织 ShinyHunters 声明已入侵多个与美国联邦调查局（FBI）相关的服务，并窃取了所有 FBI 员工及申请者的敏感数据，包含特工姓名、住址、电话及其配偶信息。404 Media 查看了其中 5,000 名涉事特工的数据样本，认为此次数据泄露可能对国家安全与反情报工作产生重大影响。泄漏的数据若落入犯罪分子或外国情报机构之手，将使 FBI 特工及其家人面临严重的追踪、骚扰与安全威胁。

  4. Pentagon says overreliance on AI contributed to missile strike on Iran school
    comments

  5. Microsoft killed FoxPro in 2007. Anyway, here's FoxPro revived
    comments

    FoxDev Studio 是一个专为 Visual FoxPro 9 应用打造的现代 IDE 与 64 位运行时，基于 Electron、React 以及编译为 WebAssembly 的 Rust 虚拟机构建，无需迁移或重写代码即可直接运行现有项目。它突破了传统 32 位 FoxPro 数据库 2GB 的文件大小限制，通过 64 位文件偏移量支持数百 GB 的单表存储。此外，系统通过 32 位桥接进程保持对传统 .fll 扩展库的兼容，并推出了引入 Lambda 表达式与 HTTP 路由 API 的 FoxScript 扩展语法。

  6. Jev in 25 Lines of Python
    comments

    本文是 NobodyWho 针对近期 AI 领域热议的 Jev 概念撰写的恶搞博文，演示了如何仅用 25 行 Python 代码实现 Jev 的核心逻辑。该实现通过 llama-cpp-python 加载本地 GGUF 模型，将分类 Prompt 对应 Token 的 Logits 计算为概率分布，实现了无需外部 API 的本地快速分类。作者指出 Jev 本质上就是基于 Prompt 的选项概率分类而非全新范式，文中同时附上了 OpenJev 等开源实现的参考链接。

  7. Claude Code reads AGENTS.md only when telemetry is on [fixed]
    comments

    Claude Code 在 2.1.277 版本中新增了对 AGENTS.md 的支持，但其加载逻辑依赖于远程特性开关（feature flag）。当用户关闭遥测（telemetry）或非必要网络流量时，或者在 Bedrock、Vertex 及第三方 Gateway 等无法解析开关的环境下，系统会在没有任何警告的情况下静默忽略本地 AGENTS.md 文件。作者指出本地文件读取不应依赖远程开关，并提出在 CLAUDE.md 中写入 @AGENTS.md 来强制导入配置作为替代方案。

  8. Fixing the Portobello Police Station Clock
    comments

    作者响应社区组织 Action Porty 的呼吁，受朋友邀请前往爱丁堡波托贝洛（Portobello）旧警察局，尝试协助调整大楼钟楼的时钟。这座始建于1877年的历史建筑曾用作议会大楼、图书馆和警察局，近期在苏格兰土地基金资助下转为社区所有并由志愿者进行修复。作者克服恐高攀爬陡峭梯子进入钟楼后，探索了可能始于1877年的原始钟表机械，该系统已被改装上电动机及夜间禁鸣控制盒。

  9. Italian parliament votes for return to nuclear energy
    comments

    意大利参议院通过新法案，为该国在切尔诺贝利核事故废除核能近四十年后重返核电铺平了道路。该法案确立了下一代核技术的监管框架，授权政府在12个月内制定有关反应堆许可、安全标准、废料管理及选址标准的实施细则，并将重点放在小型模块化反应堆（SMR）上。梅洛尼政府期望借此保障能源安全并实现气候目标，但该计划仍面临缺乏永久核废料处置库、高昂建设成本以及环保组织和反对党的强烈阻力。

  10. Claude discovers a novel enzyme system with CRISPR-like repeats
    comments

    Anthropic 成立了生命科学研究小组及实验室，致力于利用 Claude 智能体探索 DNA 数据集并自主驱动生物学新发现。在一项研究中，Claude 自主分析了超 20 万种逆转录酶，成功发现一种存在于噬菌体中、带有类似 CRISPR DNA 重复序列的全新酶系统（ART）。初步实验证实该 ART 阵列可表达为特定的短 RNA 序列，展示了 AI 智能体自主识别生物学异常并推进科研探索的巨大潜力。
