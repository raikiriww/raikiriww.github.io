  1. Apple broke an essential presentation feature of iPads
    comments

  4. Security advisory: Critical remote code execution vulnerabilities, update now
    comments

    PHP 官方发布紧急安全通告，修复了涉及内存耗尽损坏（CVE-2026-109618）与陈旧全局状态复用（CVE-2026-109619）的两个严重漏洞（CVSS 9.2），该漏洞可致未经身份验证的远程代码执行（RCE），其中 mod_php 环境风险最高。漏洞波及所有处理 Web 请求的 PHP 部署环境，官方已通过发布 PHP 8.5.12、8.4.27、8.3.36 和 8.2.35 完成修复，并为旧版本提供了极简源码反向移植补丁。官方强调立即更新是唯一完整的解决方案，针对无法立即升级的环境则建议采取设置 memory_limit=-1、限制请求体大小、禁用 session.upload_progress 及关闭致命错误回溯等措施降低攻击面。

  5. The Future of CSS
    comments

    随着各大主流浏览器厂商着手筹划 Interop 2027 标准，作者 Josh W. Comeau 盘点了多项备受期待的前沿 CSS 提案。在样式表现与动画方面，提案包括利用 @function 定义原生函数与坐标转换、通过改变 border-box 绘制斜角和自定义边缘的 corner-shape 与 border-shape，以及支持 auto 等关键字过渡的 interpolate-size。在布局控制与无障碍方面，涵盖了检测回退位置的锚点容器查询、允许在 calc() 中动态运算父级属性值的 inherit() 函数，以及根据网格视觉排版校正 Tab 键导航焦点的 reading-flow 特性。

  6. The 1.5°C goal of the Paris Agreement is no longer viable
    comments

    联合国环境规划署（UNEP）发布的《2026年排放差距报告》指出，将全球升温控制在1.5°C以内的《巴黎协定》目标已无法实现且突破该阈值已不可避免，新的底线任务是严防升温突破2°C并力争在本世纪末回落至1.5°C。为达成这一路径，全球温室气体排放需在2025年基准上于2030年削减18%、2035年削减45%，而各国现有国家自主贡献（NDC）承诺的减排力度严重不足。报告呼吁到2035年将可再生能源产能提升至三倍并大幅压缩化石能源份额，同时必须通过造林及工程化封存技术在本世纪末前从大气中清除约3200亿吨二氧化碳。

  7. Eight Bits of Trust: eMudhra's CA keys cracked in milliseconds
    comments

    安全研究人员披露证书机构 eMudhra 签发的 8 个中级 CA（涵盖 TLS 与代码签名）存在致命弱密钥缺陷，其 P-384 椭圆曲线私钥前 47 字节全为零且仅含 1 字节有效值，使得攻击者数毫秒内即可暴力破解还原私钥。尽管主流浏览器已紧急拦截并移除根证书，但由于 curl、Python、CI/CD 及物联网设备等非浏览器客户端默认不检查证书吊销与证书透明度，仍面临严重的伪造证书中间人攻击风险。调查显示该事件系密钥仪式脚本错误及人为误用弱密钥所致，暴露了长周期嵌入式设备与非浏览器生态中吊销机制失效的安全隐患。

  8. PHP 8.2.35
    comments

    PHP 开发团队发布了 PHP 8.2.35 安全更新，重点修复了两个可能导致未经身份验证远程代码执行的严重漏洞（CVE-2026-109618、CVE-2026-109619）。官方表示目前不存在完全有效的缓解措施，升级是唯一的安全选择，强烈建议所有 PHP 8.2 用户立即更新。此外，PHP 8.2 将于 2026 年 12 月 31 日正式停止生命周期支持（EOL）并不再提供安全补丁，用户需尽早规划迁移至受支持版本。

  9. Today's PHP security release, and how we're strengthening security
    comments

    PHP 官方发布了涵盖多个分支的紧急安全更新，修复了因内存耗尽（OOM）损坏与全局状态残留引发的两个严重远程代码执行（RCE）漏洞（CVE-2026-109618 与 CVE-2026-109619），并敦促用户立即升级。相关漏洞触及核心内存管理与错误处理机制，经 Calif、OpenAI 及 Wiz 等外部研究团队确认危害后，PHP 基金会将其列为最高优先级并推进了跨分支修复。协调披露过程中虽遭遇编号泄露、误发 PoC 视频以及分发商提前打破禁运等波折，官方仍快速调整节奏交付了修复方案。PHP 基金会强调基础安全维护面临资源与决策挑战，正推进团队体制改革，并呼吁依赖 PHP 的行业机构提供持续资金赞助。

  10. EA is shutting down BioWare
    comments

    电子艺界（EA）宣布正式关闭拥有逾30年历史的传奇RPG工作室BioWare，并同步终止处于早期开发阶段的下一代《质量效应》（Mass Effect）游戏项目，同时伴随全公司约400名员工的裁员。此轮重大调整紧随EA以550亿美元被私有化收购之后，标志着公司对业务线与战略重心的全面精简。未来EA将集中资源推进《战地》新作、漫威《钢铁侠》、新《星球大战 绝地》以及EA SPORTS等核心项目；此外据报道，亚马逊旗下的《质量效应》改编剧集未受影响且仍在开发中。
