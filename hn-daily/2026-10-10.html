  1. 2D Vehicles
    comments

    作者 Pat Kerr 介绍了其在 1996 年编写的 2D 物理原型，该原型后续被移植为初代《侠盗猎车手》（GTA）的车辆系统核心，并在诞生 30 周年之际以 JavaScript 重构为网页项目 Motion Lab。系统核心采用了当时游戏中罕见的 2D 刚体动力学，统一管理线速度、角速度与力矩，使物体在外壳与行为切换下支持汽车、飞船及砖块三种模式。针对车辆模拟，作者设计了一种将车轮速度分解为前向滚动与侧向抗力的简化阻尼模型，在无需复杂真实摩擦力学计算的情况下实现了极具特色的驾驶操控与漂移手感。

  2. Show HN: Let your AI agents paint big arrows, boxes and text on your screen
    comments

    big-arrow-on-the-screen（bigarrow）是一款专为 macOS 设计的开源命令行工具，可作为 Claude Code 和 Codex 等 AI Agent 的扩展技能使用。当智能体在系统操作中遇到需要人工介入的步骤（如系统权限授权、2FA 验证或应用引导）时，该工具能在屏幕顶层绘制醒目的箭头、线框与附带复制按钮的提示标牌来精准指引用户。该工具采用纯 Swift 编写，具备置顶显示但不夺取键盘焦点、允许鼠标点击穿透目标元素以及超时或完成后自动销毁等特性。

    comments

  5. YouTuber Says Cops Visited Him After He Built a Flock-Style Camera to Track Cops
    comments

  6. REA Reverse – Engineer Anything
    comments

    REA 是一款面向 AI 编程智能体的逆向工程工具，支持协助智能体分析原生二进制文件、JavaScript 与 Electron 应用以及浏览器运行时行为。该工具能够自动提取并向智能体提供目标程序的底层指令、反编译代码及运行脚本，替代了繁琐的人工反汇编与单步跟踪流程。借助 REA 提供的上下文，智能体不仅能解释深层业务逻辑，还能直接复现与重建功能，例如还原 Chrome 恐龙游戏的加速度规则或重构 Windows 计算器的百分比计算机制。

  7. Telegram Desktop vulnerability allowed any user's file to be stolen
    comments

    Telegram Desktop（7.2.8 及更早版本）存在高危漏洞（CVE-2026-107181），其单实例进程间通信（IPC）通过本地 Socket 传递指令时未对分号进行转义，导致攻击者可通过恶意 tg:// 链接注入 IPC 指令。注入指令可进一步调用缺乏鉴权的内部协议 interpret:，并结合群聊附件默认自动下载到固定路径的机制，加载预置指令文件以实现任意本地文件读取。攻击者可将受害者的敏感文件外发至指定聊天频道，并在未设置本地密码的默认配置下窃取并解密会话凭据，最终实现单次点击完全接管账户。

  8. `123456' password used in Danish CPR data breach
    comments

    丹麦国家公民登记系统（CPR）日前发生严重数据泄露，约880万人的个人信息遭到暴露，起因是拥有合法查询权限的IT公司Pays ApS凭证被黑客入侵。调查显示该公司安全防护极其脆弱，包括管理员在内的至少三个账户竟然使用了“123456”作为密码。黑客借此在近22天内进行了约1400万次非授权查询，直至官方收到异常庞大的查询账单后才察觉并阻断此次泄露。

  10. Bitwarden Dual License Model
    comments

    Bitwarden 官方宣布，自下一个版本起在各大应用商店分发的应用将切换为商业许可构建版本，但普通用户无需任何操作且现有功能与永久免费计划保持不变。官方强调此举并非走向闭源，GitHub 上的 GPLv3 开源代码库将继续更新，用户仍可自由审计代码并自建托管，变更主要旨在约束二次打包转售行为。针对未来双版本的差异，官方表示部分新功能与组件将仅在商业版本中提供，新开发特性也将逐案评估适用的许可类型。
