  1. Start Doing Graph Theory

  2. Wikipedia's Cleanup of AI-Generated Content
    comments

    面对日益隐蔽的AI生成文本与普遍的错误引注问题，维基百科志愿者发起的WikiProject AI Cleanup正通过出台限制规则及研发检测工具来筛查和清理违规内容。尽管第三方检测显示新内容中AI占比有所下降，但模型快速演进使得机器写作在结构上更难甄别，维基百科仍面临工具滞后与初学者规范落地的双重挑战。在AI搜索分流访问量的背景下，维基百科不仅坚守其作为不可替代的“纯人类编写语料库”核心身份，也在积极探索适应AI时代的引用归属机制与人机协作模式。

  3. Anthropic trained Claude on illegally obtained Stanford professors' books
    comments

    据《斯坦福日报》报道，联邦法官在 Bartz 诉 Anthropic 版权和解案中裁定，Anthropic 从影子图书馆非法获取包括 10 余位斯坦福教授在内的受版权保护书籍来建立中央库训练 Claude 模型，但同时认定合法获取书籍训练大模型属于合理使用。托比亚斯·沃尔夫（Tobias Wolff）和李昌来（Chang-Rae Lee）等多位教授因不满该案中平均每部作品仅约 3000 美元的和解赔偿，选择退出并另行提起 Cruz 诉讼，寻求每部侵权作品最高 15 万美元的法定赔偿金及永久禁令。该系列案件凸显了 AI 训练面临的高昂授权交易成本，并促使作家协会等组织积极推动国家层面立法以强制实行 AI 训练版权许可制度。

  4. Survival LLM: AI assistant and emergency library that runs on your own computer
    comments

    Survival LLM 是一款面向 Mac 和 Windows 的免费开源离线 AI 助手与应急资料库，完成初始配置后即可在断网环境下完全于本地运行。系统内置涵盖约 93 万篇维基百科条目以及 FEMA 应急指南、CDC 指导、医学百科和 iFixit 维修手册等权威资料，回答停电防护、急救等应急问题时均会标注并高亮出处来源。它能根据计算机内存大小自动下载匹配的本地模型，全程无需注册账号且不上传数据，同时支持导入用户私有的应急手册和文档进行本地检索。

  5. Git for the US Code
    comments

    Lexifina 的 Alan Yahya 针对律师与法律大模型难以精准追溯特定历史日期有效法律条文及立法出处的痛点，构建了类似 Git 的《美国法典》（US Code）版本历史系统。该项目通过按时间顺序重放 2017 年以来的修订指令，可核验地精确还原了九卷法典中 365 处变动中的 361 处，并标注了各修改生效的具体法案与生效日期规则。用户能够查询任意日期生效的法规文本并查看基于法案着色的词句变动，但系统目前在处理法规溯及既往效力及非常规生效日期注释方面仍有一定局限。

  6. Apple's git still trusts the compromised eMudhra certificates
    comments

    在收到 eMudhra CA 证书机构沦陷通知 11 天后，macOS 自带的 git、curl 和 python3 等开发者工具仍默认信任受损证书，且 macOS 27.2 更新不仅未予修复还覆盖了用户的手动规避设置。攻击者可借此对网络连接实施中间人劫持，导致 git 代码拉取被注入恶意代码、推送被篡改或 GitHub 访问凭据泄露。虽然苹果已在 Safari 中提供保护，但在官方更新系统证书库前，开发者需手动移除受损根证书并警惕 CI 构建环境的供应链风险。

  7. ICE Is Running One of the Largest Anti-Left Surveillance Ops in US History
    comments

    美国明尼苏达州针对反移民执法抗议者的“明尼苏达15人”案，曝光了国土安全部（DHS）及移民与海关执法局（ICE）针对国内左翼社会运动展开的历史性大规模监控与渗透行动。调查动用了近120名国土安全调查局（HSI）特工并派出卧底深入教会和加密通信群组，同时启用了“死神”无人机、爱国者法案反恐金融追踪工具以及商业数据平台来识别活动人士并调取记者通话记录。法律专家与前官员指出，该行动的涉案人数、技术侵入性及庞大数据规模已超越冷战时期的反情报计划（COINTELPRO）和中情局混沌行动，标志着反恐与移民执法权力被大幅挪用于压制美国国内异见人士。

  8. Gemini 4 Carbon
    comments

  10. Why is this fingerprinting script creating bioweapons?
    comments

    作者在逆向分析全网 Canvas 浏览器指纹脚本时，发现俄罗斯安全公司 Servicepipe 部署的一款反爬虫脚本中充斥着计算生物武器剂量、合成毒物及系统越狱等大量敏感词与危险函数名。深入分析表明，这是一种针对 AI 辅助分析的“反 LLM 混淆”对抗手段，旨在通过故意触碰大模型的安全审查红线，阻止逆向工程人员利用大语言模型反混淆其代码。剥离这些诱发模型拒答的安全绊线与虚假命令后，该脚本在实际功能上仅用于常规收集浏览器环境与 WebGL 渲染特征等设备指纹。
