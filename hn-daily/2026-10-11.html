  2. The Lightbulb Computer
    comments

    针对传统屏幕的局限以及头显/智能眼镜在佩戴体验与社交隔阂上的不足，前苹果设计师 Guillaume Ardaud 提出了“灯泡电脑”（Lightbulb Computer）设想，将高分辨率微型投影仪与计算机视觉整合为灯泡形态，既可便携摆放，也可直接旋入标准天花板灯座提供全室空间计算。该设备结合语音交互、手势指向追踪与实时视觉分析，能直接将食谱、巨幅地图、环境看板等数字信息投影并叠加到物理表面，甚至能直接指向操控智能家居。相比需要人人佩戴且算力功耗受限的面部设备，这一投影计算方案更具沉浸与社交共享性，并通过实体原型验证了可行性，辅以端侧处理和硬件物理开关来保障用户隐私。

  3. A city-building game in which the city would prefer you didn't
    comments

    《Discretionary Review》是 Oliver Sin 开发的一款模拟在旧金山推进住房建设的城市营造游戏，背景设定于 2015 年的旧金山市政厅政治环境。玩家需在地图选址立项，直面立场分歧的市参事会与规划委员会，并运用 SB 35、CEQA 豁免等现实政策法规应对建造成本与贷款利率波动。游戏核心围绕听证会、投资审查与声望机制展开，玩家必须通过推进项目并做出妥协来维持声望，若声望过低则会引发公众游行抗议。

  4. Build your own decision model
    comments

    文章介绍了如何基于开源大语言模型构建单次前向推理的快速决策模型：通过将候选输出严格约束在固定选项 token 上进行单步概率计算，避免了多轮自回归生成的高延迟开销。针对模型直接输出的 token 概率存在严重过度自信、导致预测置信度显著背离真实准确率的问题，作者通过 CommonsenseQA 数据集进行评估验证。最终采用温度缩放（Temperature Scaling）技术平滑并重塑概率分布，成功将决策模型的置信度得分与实际准确率对齐校准。

  5. LineageOS 24
    comments

  6. 3rd Yandex Cloud Data Center Was Hit
    comments

    Yandex Cloud官方状态页通报了编号为2136的重大故障事件，其ru-central1-a可用区（对应弗拉基米尔数据中心）因供电中断而整体瘫痪，使平台进入紧急运行状态。该事件系Yandex近期第三处遭受打击并停运的数据中心，导致托管数据库、对象存储及Kubernetes等多项核心云服务出现不可用或性能降级。官方团队已紧急开展故障转移与抢修，暂停发放新增云资源配额，并建议关键业务客户尽快启用备用容灾方案。

  7. Bot traffic from Yandex
    comments

    Cloudflare Radar 统计数据显示，来自自治系统 AS13238（Yandex LLC）的 HTTP 请求中机器人流量占比高达 99.6%，人类真实访问仅占 0.4%。相关页面还展示了 Cloudflare 针对机器人生态推出的管理功能，包括支持通过 HTTP 402 协议向消耗 API 与工具的 AI Agent 收费的 Monetization Gateway 网关。此外还涵盖用于追踪与管理爬虫提交的 BotBase 平台，以及可自动同步 robots.txt 与 AI 访问偏好的 Bot Preference Sync 服务。

  9. I paid people to try and follow my README
