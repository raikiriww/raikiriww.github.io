  1. CIA funding helped keep NeXT afloat in the 80s
    comments

  2. Malicious Rust crate Arrayref runs a build-time payload
    comments

    2026年8月，流行Rust库arrayref的维护者账号遭遇入侵，发布的0.3.10版本引入了拼写劫持的恶意依赖包proc-macro1。该恶意包在项目编译时会自动解码Base64格式的C2服务器地址，下载并静默运行针对不同系统架构的恶意后门。攻击者通过撤回（yank）历史安全版本来强迫用户升级，且其构建脚本利用Unix下的临时执行文件及Windows下的WScript成功逃逸了Cargo构建监控以实现持续运行。

  3. The August 17 outage
    comments

    GitHub于8月17日因流量达到新高峰导致关键基础设施容量失效，发生了一起持续近8小时的严重故障，影响了身份验证、GitHub Actions及Copilot等多项核心服务。为提升平台可靠性，GitHub已紧急增加超300万个CPU内核及大量高 speed 存储，并加速向Azure迁移（目前承载约58%的平台负载）。此外，团队正通过限制服务间重试、优化报警机制并重构monorepos架构来消除瓶颈，以实现读容量的线性扩展并防止级联负载故障。

  4. AI companies destroy physical books – let's scan rare books before it's too late
    comments

    文章指出，AI公司正大量采购包括绝版和稀有书籍在内的实体书，并在拆解后进行低成本的高速“破坏性扫描”以获取训练数据，随后将这些实体书彻底销毁。此举动机在于获取2022年前未经机器污染的高质量文本，同时通过购买实体书所有权来规避版权法律责任，并防止竞争对手获取相同的数据源。为此，Anna's Archive 呼吁全球志愿者在此类文化遗产流失之前，尽快对稀有图书进行无损扫描并上传，以防人类共同的知识被私人公司独占。

  5. AI companies destroy physical books – let's scan rare books before it's too late
    comments

    Anthropic等AI公司被指正秘密大量购买、扫描并销毁物理书籍，以此获取未受机器污染的数据训练大语言模型，导致人类知识面临被私有服务器垄断的危机。为此，影子图书馆“安娜的档案”（Anna’s Archive）紧急号召全球志愿者扫描并上传各类珍贵书籍和文献以实现知识留存。该组织正致力于构建数字化的亚历山大图书馆，并为做出贡献的志愿者提供会员资格或扫描费用补贴。

  6. DeepSeek-v4-flash-vision-exp
    comments

    DeepSeek 推出 deepseek-v4-flash-vision-exp 视觉模型，支持 JPEG、PNG、GIF 和 WebP 格式，用户可通过 Base64 编码、外部 URL 或 Files API 三种方式输入图像。Files API 适用于图像复用或超过 32 MiB（最大支持 64 MiB）的大图，单次请求最多支持 600 张图片。输入图像在推理前会被自动缩放，每张图片最多消耗 384 个 Token，同时该模型也兼容 Anthropic 的接口和 Responses API。

  10. Felony Bench
    comments
