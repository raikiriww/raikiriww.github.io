  1. Show HN: I made a flight simulator, except you're just a passenger
    comments

    InFlightSimulator 是一款独特的飞行模拟项目，其特点是用户并非扮演驾驶员，而是以乘客视角体验虚拟环球旅行。用户可在系统中自主挑选出发地与目的地机场，支持包括伦敦（LGW）、阿布扎比（AUH）、北京（PEK）等全球范围内的多个航点。应用整合了 Esri 的地图与卫星影像数据，选择航线后即可在线开启虚拟飞行观光之旅。

  2. Let's make quality the norm again
    comments

    挪威消费者委员会（Forbrukerrådet）发布关于循环消费者政策的报告，指出当前存在大量产品过早损坏报废的问题，呼吁重新让高质量成为标准。报告强调循环经济不仅有助于环境保护，还能巩固消费者权益并提升社会韧性。为此，报告进一步阐述了如何通过政策引导，使循环消费选择对消费者而言更加便捷、安全且具吸引力。

  3. Why I'm still bearish on LLMs after Navier-Stokes
    comments

    作者对大语言模型（LLM）的全面自动化前景持看空态度，认为前沿实验室的高估值脱离现实，因为现阶段模型仅能在狭窄的训练任务附近泛化，遇到微小扰动极易发生失效或奖励破击（reward hacking）。解决该问题依赖极其昂贵且稀缺的领域专家进行严格规范编写（rigorous specification），而人工审核作为替代方案不仅难以扩展且同样易受误导。因此，LLM 在绝大多数领域中只能作为需严格监督的高效助手，结构性限制决定了多数企业难以部署完全自主的 AI。

  4. Gemini 3.8 Live and 3.8 Live Extended Thinking
    comments

    Google推出Gemini 3.8 Live与3.8 Live Extended Thinking两款实时语音模型，分别专注于规模化性价比与高复杂度多步推理。Gemini 3.8 Live支持近实时视觉处理与97种语言自动切换，而Extended Thinking具备边思考边表达的并行推理能力，在Speech to Speech与τ-Voice等多项Agent基准测试中取得领先。所有生成的音频均嵌入SynthID水印以确保内容可追溯性，目前已在Gemini API、Google AI Studio及Workspace等平台陆续上线。

  5. An update on Wayback Machine access
    comments

    因遭受海量自动化流量冲击，Internet Archive 的 Wayback Machine 采取了防护措施以维持服务运行，并重写了 429 错误（请求过多）的拦截提示。由于防护机制有时会误封锁正常用户，团队正在努力提升区分恶意机器人与真实用户的精准度。若认为被误拦截，用户可将操作系统、浏览器和 IP 地址发送至 info@archive.org 申请排查。

  6. Building a Linux GPU Driver for the M4 Mac Mini in One Month
    comments

    Cody Ho 与 Niklas 在约一个月内利用无污染逆向工程与 AI 辅助，为 M4 Mac Mini 及 MacBook Neo 成功开发出符合 OpenGL ES 3.0 标准的 Linux GPU 驱动程序。团队借助 Hypervisor 跟踪重放与实时探测技术，解析了 Apple AGX GPU 复杂的 RTKit 固件 ABI 与用户态指令集，并使用 Rust 编写了内核驱动及自定义着色器编译器。该驱动已能在 M4 Mac Mini 上流畅运行 Chrome 和 Firefox 的 WebGL 渲染，并以 200fps 运行《Minecraft》，后续计划进一步完善并支持 Vulkan。

  7. Apple Reference Image: A New Approach for Verified Photography
    comments

    Apple 推出用于 iPhone 18 Pro 系列的可验证摄影方案 Apple Reference Image，旨在应对 AI 伪造与图像篡改对照片真实性带来的挑战。该技术通过相机传感器硬件直接对原始像素加密签名生成“安全数字底片”，并借助 Private Cloud Compute (PCC) 在透明且隐私的环境中完成后续渲染，全流程保障语义真实性。此外，系统采用 RSA-3072 与 ML-DSA-87 复合后量子签名抗击未来破解风险，并支持欺诈撤销机制与无须暴露摄影师身份的隐私保护。

  8. Mistral X Mozilla: Private, Multilingual AI Browsing
    comments

    Mistral 与 Mozilla 达成合作，由 Mistral 模型为 Firefox 的 AI 浏览助手 Smart Window（测试版）提供支持，已率先在法国和北美推出，并计划后续扩展至英国与德国。该助手能帮助用户分析复杂搜索、追溯历史标签页信息并整合内容，同时针对各地区语言与文化语境进行了专门微调。双方强调隐私保护与开源控制权，默认不在服务器保存对话记录并遵循零数据留存原则，旨在为用户提供具备本土化理解力与自主掌控权的主权 AI 浏览体验。

  9. EU chief opens door for Canada to become 'associate member'
    comments

    欧盟委员会主席冯德莱恩提议让加拿大成为欧盟首个“联系成员国”，旨在国防、人工智能、能源及关键矿产等关键领域深化合作。对此，美国总统特朗普警告称若该合作带有敌意，将对欧盟加征严重关税甚至停止贸易。此外，冯德莱恩还在施特拉斯堡讲话中提出了成立包含英国和乌克兰的欧洲安全理事会、限制未成年人使用社交媒体等多项政策主张。

  10. Hackers Got Inside a Flock Camera
    comments

    黑客组织 stegan0gram 拆卸并逆向工程了一台 Flock Safety 车牌识别摄像头，提取了设备未加密分区并利用留存密钥解锁了海量监控数据。404 Media 和 WIRED 的联合调查显示，该摄像头的计算机视觉软件不仅记录车辆和车牌，还明确检测行人、自行车及车贴等细节特征。这一事件揭示了 Flock 允许全美数千家机构跨区域共享调阅数据的全国性监控网络，引发了公众对隐私与执法滥用的强烈争议。
