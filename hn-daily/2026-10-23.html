  3. Run full iOS 16.5 firmware on Android Devices
    comments

    HackiOS 是一个开源独立研究项目，通过自研 EFI 加载器、UEFI 移植与驱动兼容层，在搭载骁龙 778G 的 POCO X5 Pro 5G 安卓设备及 QEMU 模拟器上成功引导苹果 XNU 内核，并直接运行未做修改的 iOS 16.5 原生用户空间。该方案通过 fastboot 将系统全部加载至内存中运行而不刷写本地存储，目前已实现触控手势、部分系统应用、Wi-Fi 与 Adreno GPU 硬件渲染等基础功能。项目定位为技术实验平台而非替代性 ROM，当前蜂窝网络、蓝牙、内核充电与 Secure Enclave 认证等功能仍无法使用，重启后即可恢复原 Android 系统。

  6. Local Wikipedia: Wikipedia, but only for things a half hour walk from you
    comments

    Local Wikipedia 是一个基于维基百科地理编码条目的非官方探索工具，专门展示用户步行半小时范围内的周边事物。当邻近条目不足 25 个时，系统会自动扩展获取约 6 英里内最近的 25 个条目，上限最多保留最近的 500 个。该工具注重隐私，用户的位置数据仅保存在本地浏览器中，分享的链接不会泄露位置信息。

  7. Docker is weird
    comments

    作者在自制容器运行时时揭示了 Docker 底层诸多反直觉的实现细节。容器并非真实独立的虚拟实体，而是由 namespaces、cgroups 等内核特性限制的宿主机普通进程，其镜像本质上也只是通过 chroot 或 pivot_root 挂载的普通文件目录。核心运行时 runc 所使用的 Go 语言由于具备多线程且缺乏原生 fork 机制，迫使其借助前置 C 模块及重新执行自身二进制（exec /proc/self/exe）来模拟 fork 与单线程系统调用。此外，由于大量底层接口通常需要 root 权限，无 root（rootless）容器运行时往往不得不在用户态重写整个网络栈以实现网络隔离。
