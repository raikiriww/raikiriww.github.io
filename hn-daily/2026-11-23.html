  1. A Beginner's Guide to Local AI with Inkling, Qwen, and Unsloth
    comments

    本文介绍了在 Windows 平台使用 Unsloth Desktop 搭建家庭本地 AI 助手的入门指南，旨在摆脱云端商业模型的订阅成本、使用限制与隐私风险。文章详细梳理了显存容量与模型量化精度的匹配策略，演示了在 RTX 5090 上运行 Qwen3.8-27B 或 Inkling 2 Mini 并平衡长上下文窗口的方法。用户只需完成客户端安装、模型下载与上下文设置三步即可启动本地模型，并可通过内置的局域网功能实现家庭跨设备共享访问。

  2. Free alternative TV network built from the Internet Archive's forgotten videos
    comments

    SPELUNKR（spelunkr.tv）是一个基于互联网档案馆（Internet Archive）海量被遗忘历史视频资源构建的免费另类网络电视平台。该平台模拟传统有线电视体验，提供 24 小时全天候的多频道同步线性轮播，涵盖复古电视节目、经典广告和小众老电影等怀旧影像，重新营造全球观众同时收看的共时体验。网站采用复古电视界面与像素字体设计，所有内容均直接串流自 Internet Archive，并支持将播放画面投屏至电视且将移动端作为遥控器使用。

  3. XNU Linux: Full OS X GUI Userspace on Linux
    comments

    xnulinux 将苹果开源的 XNU 内核编译为可加载内核模块（xnu.ko），直接运行在未经修改的 arm64 Linux 内核中，无需 Hypervisor 即可让 macOS 与 Linux 进程在同一 CPU 上原生并行。系统通过 FKI 接口模块由 Linux 分配内存、定时器、网络并桥接 GPU/DRM，成功在 Ubuntu 等宿主环境上引导出包含 WindowServer、Dock 及 Safari 等应用的完整 macOS 桌面。该项目已在 Apple Silicon 虚拟机及 NVIDIA DGX Spark 裸机上验证成功，仓库严格区分 GPL 与 APSL 许可证边界且不分发苹果专有二进制文件。

  4. GLM-5.4: Toward generalized coding with our first loop transformer
    comments

    GLM-5.4 是基于首个循环 Transformer 架构（Loop Transformer）打造的旗舰模型，通过对共享层块进行多轮迭代执行，在不增加参数量的条件下深化推理能力，智力水平媲美 2T-3T 参数级模型。该模型在 750B 规模基座上将 28 层循环两次，通过门控渐进更新、混合 KV 缓存与稀疏注意力索引复用等机制大幅优化了内存与计算开销，使推理链条更高效且思维链标记消耗降低 10–14%。GLM-5.4 标志着“泛化编程”（Generalized Coding）的开端，支持利用代码实现 CAD 机械建模、游戏开发与 3D 渲染等多领域复杂任务，团队计划在完成安全加固后负责任地开源模型权重。

  6. Jensen Huang Reinstated as Nvidia CEO
    comments

  7. Ladybird is now in alpha
    comments

    comments

  10. Per Arm's request, this site will be discontinued on 4 December 2026 :(
    comments
