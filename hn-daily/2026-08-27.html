  10. Saving 100 terabytes of memory by optimizing 1.1.1.1's DNS cache
    comments

    Cloudflare 通过对其 DNS 缓存系统 Big Pineapple 进行五项 Rust 级别的内存布局优化，成功将每个条目的内存占用降低了 56%，在全网服务器中释放了约 100 TB 的内存。具体优化包括使用 Box<[T]> 和 Box<str> 代替 Vec 和 String、合并记录段为单列表并使用 u16 偏移、省略与查询域名相同的记录所有者，以及将大 enum 变体放入堆中并最终采用原始字节流紧凑存储。这些改进不仅减少了堆分配和空间浪费，还使系统插入吞吐量提升了 43%，查询延迟降低了 19%。
